# Fresh-Start Non-Reuse Policy

## Project

gu_asl_fresh_start_2026

## Rule

This repository represents a completely new experimental evidence track.

The following must NOT be imported, copied, resumed or reused from any
previous experimental implementation:

- model source code
- trained model weights
- checkpoints
- optimizer states
- scheduler states
- old train/validation/test folds
- old LOSO manifests
- old template-holdout manifests
- old caches or tensors
- old vocabulary ID mappings
- old normalization statistics
- old prediction files
- old metric files
- old confidence thresholds
- old tuned hyperparameters selected from previous results
- old result tables or figures as new experimental evidence

## What may be used

The following may be used as scientific or source context:

- the original author-provided Gu dataset
- label_no_order.txt
- label_order.txt
- the Gu, Oku and Todoh paper
- other published literature
- knowledge of methodological risks that must be independently re-tested

Examples of risks that will be checked again from scratch include:

- duplicate leakage
- incorrect CTC output lengths
- decoding padded timesteps
- uneven subject/template support
- ambiguous feature semantics
- signer-independent evaluation limitations
- Swin representation assumptions

Knowing that a risk may exist does not permit reuse of an old audit result.
The fresh project must independently verify it from the source data.

## Evidence rule

Only artifacts generated by this repository after the fresh-start boundary
may enter the final fresh-project experimental evidence.

Previous experimental results may be discussed historically only when
explicitly identified as previous work and must never be silently mixed
with the fresh results.
